# WWF-IT & IARAN Pathway 2030

Dynamic macro-network workspace for the WWF Italia Pathway 2030 Theory of Change review.

The app represents the current structured model as five levels:

1. **Goal strategici**
2. **Obiettivi**
3. **Risultati ufficiali**
4. **Attività di livello 4**
5. **Attività di livello 5**

The network is composed from the official strategic framework and the readable elements extracted from the results maps shared for the project. Raw source documents are not included in this repository.

## Run locally

```bash
npm install
npm start
```

The app will run on the port provided by the environment, or on `3000` locally.

## Railway

This repository is ready to deploy on Railway as a Node/static app. Railway should run:

```bash
npm install
npm start
```

No custom domain is required for the first deployment; Railway can provide a generated URL.
